Как добавить запись на сайт

Сайт состоит из обычных HTML-файлов. Базы данных нет, все правки делаются в тексте.

Добавить программу, язык или репозиторий

  1. Открой нужную страницу, например tools.html, в редакторе кода
  2. Найди блок article внутри нужной группы
  3. Скопируй блок целиком и вставь под ним
  4. Поменяй название, описание и ссылку
  5. Сохрани файл и отправь изменения в GitHub

Добавить Python-пакет

Скопируй блок article на странице python.html. Поменяй имя пакета в трех местах: id, value и текст. Атрибут data-sets задает готовые наборы, data-version нужен для режимов с версиями.

Добавить файл

  1. Положи файл в папку files
  2. Запусти python make_hashes.py
  3. Скопируй выданную строку в таблицу на files.html
